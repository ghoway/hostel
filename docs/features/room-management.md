# Room Management

---

# Purpose

Manages room types, physical rooms, amenities, and room statuses.

---

# Room Type

Room types represent sellable room categories.

Example:

- Standard
- Deluxe
- Superior

---

# Physical Rooms

Physical rooms belong to room types.

Example:

- Room 101
- Room 102
- Room 201

---

# Room Statuses

- available
- occupied
- reserved
- dirty
- cleaning
- maintenance
- out_of_order

---

# Amenities

Amenities belong to room types.

Examples:

- WiFi
- Breakfast
- Dinner
- TV
- Parking

---

# Room Images

Room types support multiple images/gallery management.

---

# Capacity Rules

Room types must support:

- maximum adults
- maximum children
- maximum infants
- maximum extra beds
