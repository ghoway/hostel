# Room Assignment Architecture

---

# Purpose

Defines how room assignment works operationally.

---

# Core Principles

- Guests reserve room types, not physical rooms
- Physical rooms are assigned later
- Room assignment is operational, not commercial

---

# Recommended Approach

Physical room assignment should preferably happen during check-in.

This provides:

- operational flexibility
- easier maintenance handling
- better room rotation
- easier housekeeping coordination

---

# Example

Guest books:

- Deluxe Room

Front Office later assigns:

- Room 203

---

# Room Assignment Rules

- assigned room must belong to the correct room type
- assigned room must be available
- assigned room must belong to the correct hotel

---

# Room Status Impact

Check-in:

- room becomes occupied

Check-out:

- room becomes dirty or cleaning
